## Возможности

### Подготовка файла к импорту

**Загрузить пример → Подготовить к импорту → Прочитать столбцы.** Первая непустая
запись считается заголовком. Можно исключать, переименовывать и переставлять
столбцы; задавать обязательность и тип: текст, целое, число с десятичной точкой,
базовая проверка формата email. Значения не преобразуются в числа: `001` сохраняется.
Email-проверка не подтверждает существование адреса.

Отмеченные столбцы «Ключ» образуют один составной уникальный ключ с учётом
регистра, после выбранного удаления пробелов. Пустой ключ отклоняется;
принимается первое корректное вхождение. Ошибочное число столбцов, обязательные
пустые поля, неверные типы и повторные ключи видны в отдельном списке.

**Сформировать файл импорта** создаёт `import-ready.csv`, отдельный
`rejected-records.csv` с причинами и исходными ячейками в JSON, а также JSON-отчёт.
Номер записи — логическая позиция в CSV, не обязательно физическая строка текста.
В превью по 30 принятых и отклонённых записей; в скачиваемых файлах — все.
Для примера отметьте `sku` как ключ, `email` как обязательный Email, `price` как
число с точкой: получится одна принятая и четыре отклонённые записи.

Ограничения: до 200 выбранных столбцов и 200 000 ячеек результата, плюс прежние
лимиты источника. Настройки сопоставления хранятся только в памяти вкладки.
Защита формул по-прежнему превращает отрицательные числа в текст — проверьте
настройку для своей системы импорта. С выключенным режимом работает прежняя
очистка без предположения о заголовке. Автоматической загрузки в CRM/магазин нет.

| Возможность | Поведение |
| --- | --- |
| Очистка | Обрезка пробелов и удаление пустых строк |
| Повторы | Необязательное удаление точных повторов со счётчиками |
| Экспорт | CSV и JSON-отчёт; защита от формул включена |

Вставьте CSV или выберите файл UTF-8, затем явно укажите разделитель: запятую, точку с запятой или табуляцию. Можно убрать пробелы по краям, пустые строки и точные повторы. Превью показывает первые 30 записей; скачиваются полный очищенный CSV и отчёт JSON. Заголовок не предполагается. Повторы сравниваются после обрезки пробелов, до защиты от формул. Разное число столбцов вызывает предупреждение, непустые строки сохраняются.

Интерфейс EN/RU/ES выбирается по языку браузера; ручной выбор сохраняется локально. В localStorage сохраняется только язык.

## Быстрый запуск

Вручную установите Python 3.11+. Зависимостей и автоматической установки нет.

| Система | Запуск |
| --- | --- |
| Windows | Двойной клик по `Start.bat` или `Start.cmd` |
| macOS | `sh Start.command`; для двойного клика предварительно `chmod +x Start.command` |
| Ubuntu / macOS | `sh start.sh` или `make start` |
| Среда с Python | `python app.py` |

Откройте **http://127.0.0.1:8802** после сообщения в терминале. Остановка — Ctrl+C. Другой порт: PowerShell `$env:PORT=8808; python app.py`, POSIX `PORT=8808 sh start.sh`. Сервер слушает только 127.0.0.1. Скрипты macOS/Ubuntu требуют проверки на соответствующих системах.

## Ограничения и данные

Лимиты из [app.py](app.py): 1 000 000 байт UTF-8, 10 000 логических записей, 200 000 ячеек; тело JSON — до 2 200 000 байт, поэтому экранирование иногда достигает лимита раньше. Усечения нет. Строгий парсер Python отклоняет незакрытые кавычки и посторонние символы после закрывающих кавычек; семантика данных и все диалекты CSV не проверяются. Кавычка внутри некавыченного поля может приниматься парсером.

Защита от формул включена по умолчанию: к значениям с признаками формул (`=`, `+`, `-`, `@`, начальная табуляция/перенос) добавляется апостроф. Отрицательные числа тоже становятся текстом. Проверяйте результат в целевом приложении: универсальной гарантии для всех импортёров нет.

Приложение не записывает загруженные данные на диск: обработка в памяти браузера и Python, скачивание сохраняет браузер по вашему действию. ОС может использовать файл подкачки или аварийные дампы; приложение ими не управляет. По окончании закройте вкладку и остановите процесс.

Проверяются Host/Origin, доступны только четыре статических ресурса, одновременно выполняются не более двух задач обработки. Содержимое и пути запросов не журналируются. Не публикуйте этот локальный сервер через прокси; это не многопользовательский сервис.


Проверка: `python -m unittest discover -s tests -v` или `make test`. Проверяются многострочные поля, повторы, формулы, повреждённый CSV, лимиты, разные длины строк, BOM, ограничения Host/Origin и выдачи файлов.

## Идея пилотной услуги

**Гипотеза, спрос не доказан:** очистка товарного каталога или CSV из CRM перед импортом. Согласуйте пример и критерии приёмки, проверьте результат вручную и передайте CSV с отчётом. Проверки email, объединения клиентов, оплаты, аккаунтов и гарантированного дохода здесь нет.
